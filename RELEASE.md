# Release 0.16.2 (2026-11-06)

A person who runs abcd unattended on a second account of their computer can stop those runs from their own account with one command, `abcd implement stop`, and the stop stays until their own `abcd implement stop --lift` lifts it. Each run reads the stop before its next move: it opens no lane, hands out no stage and starts no agent; an agent in a call finishes that call and its receipt is collected; then each lane's uncommitted work is saved aside, the run's reservation is released so a peer may take the work, and the day's page is written to the account's directory in the shared folder. The stop crosses accounts where each account chose the same shared folder at setup (`abcd ahoy shared-folder`), an option meant for a machine no other person shares, since every account on it can read the folder; declining leaves every other part of abcd working, and a stop then reaches only the person's own runs. Setting and lifting a stop are the person's own acts: the guard's rule and the command hold against an agent acting by mistake, and a stop binds an agent only where an operating-system account separates them. A run a stop halted stays halted after the lift until a session takes it over, and a pull request armed before the stop can still merge under it, so the day's page names each one with the command that disarms it.
