# How-to guides

Task-oriented documentation — each guide walks through accomplishing one specific
goal for a user who already knows the basics (e.g. "install abcd into a repo",
"publish a release"). Goal-focused and to the point; background belongs in
`../explanation/`.

- [`install.md`](install.md): Install abcd as a plugin, as a command-line binary, or from source.
- [`keep-memory-notes.md`](keep-memory-notes.md): Write a memory note, review and remove the notes kept for you, and see what a prompt brings back.
- [`run-a-brief-session-relay.md`](run-a-brief-session-relay.md): Run the relay a team's live brief session goes through, on your own machine over Tailscale or on the team's own relay on Render.
- [`upgrade-to-v0.12.0.md`](upgrade-to-v0.12.0.md): Upgrade to v0.12.0: the loop's renamed stage fields and the removed command spellings, each with its replacement.
- [`upgrade-to-v0.13.0.md`](upgrade-to-v0.13.0.md): Upgrade to v0.13.0: rename abcd's folder from `~/.abcd` to `~/.abcd.noindex` in a plain Terminal window, reconnect its worktrees, recover when both folders exist, refresh each managed project's block, update your own scripts, route a role to a runner from your own settings, and keep your project's conventions in `AGENTS.md` in place of `CLAUDE.md`.
- [`upgrade-to-v0.14.0.md`](upgrade-to-v0.14.0.md): Upgrade to v0.14.0: replace each retired command with its successor, move memory and source commands under library, read the release cut from the launch preview, refresh each managed project's pre-commit hook, and find the agents' commands.
