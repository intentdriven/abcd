2026-11-18 — The approver refuses a git command whose git directory, found from -C, a fixed cd or a wrapper's change of directory (env -C or --chdir, sudo -D or --chdir, unshare -w or --wd, each written whole, abbreviated or in a cluster), or named by --git-dir, GIT_DIR, GIT_COMMON_DIR, --bare or git init --separate-git-dir, stands inside the working tree and is not the working tree's own; one whose directory, or the directory git finds its repository from, the line does not fix, sudo -i or --login (the target user's home) among them, and one behind a wrapper the approver does not hold on its short list of wrappers known to leave the directory alone (env, sudo, unshare, nice, nohup, timeout, time, command, exec, stdbuf and ionice, read only through the options that list classifies as leaving the directory alone or changing it, so sudo -R, sudo -s, unshare -R and an abbreviated option are refused, and xargs, which may add git's options from its input, is left off), since naming the wrappers that change the directory one by one never closes the set and an unknown wrapper must fail closed; and, after an earlier command of the line writes, one that runs in a directory inside the working tree other than its root or its own git directories, or names a git directory inside the working tree other than its own, because git reads that directory's configuration, which may name a program, the approver judges only the working tree's own, and a write earlier in the line may make a repository where none stood when the line was read.
