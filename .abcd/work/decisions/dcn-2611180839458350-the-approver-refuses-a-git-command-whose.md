2026-11-18 — The approver refuses a git command whose git directory, found from -C, a fixed cd or a wrapper's change of directory (env -C or --chdir, sudo -D or --chdir, unshare -w or --wd, each written whole, abbreviated or in a cluster) by git's walk upward (a .git, or a bare repository whose HEAD may be a symlink), or named by --git-dir, GIT_DIR, GIT_COMMON_DIR, --bare (read where git stands when it reads it) or git init --separate-git-dir, or by a local path among the operands of push, fetch, pull, ls-remote, clone or submodule or given to --repo or archive --remote, stands inside the working tree and is not the working tree's own, a git file or commondir file being followed to where it points even from outside the working tree; one whose directory, or the directory git finds its repository from, the line does not fix, sudo -i or --login (the target user's home) and one wrapper given two changes of directory among them; one behind a wrapper the approver does not hold on its short list of wrappers known to leave the directory alone (env, sudo, unshare, nice, nohup, timeout, time, command, exec, stdbuf and ionice, read only through the options that list classifies as leaving the directory alone or changing it, so sudo -R, sudo -s, unshare -R and an abbreviated option are refused, and xargs, which may add git's options from its input, is left off), since naming the wrappers that change the directory one by one never closes the set and an unknown wrapper must fail closed; after an earlier command of the line writes, or is a git command off a short list known to leave the working tree alone (status, log, diff, show and other readers, branch and remote with no arguments), one that runs in a directory inside the working tree other than its root or its own git directories, or names a git directory inside the working tree other than its own; and every git command in a line that runs its commands out of text order and writes or changes directory anywhere; because git reads that directory's configuration, which may name a program, the approver judges only the working tree's own, and what the line's text cannot place exactly is refused rather than modelled more finely. A repository a command takes from configuration, such as a remote's URL, is not read.
