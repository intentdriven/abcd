2026-11-18 — The approver refuses a git command whose git directory, found from -C or a fixed cd, or named by --git-dir, GIT_DIR, GIT_COMMON_DIR, --bare or git init --separate-git-dir, stands inside the working tree and is not the working tree's own, and one whose directory the line does not fix, because git reads that directory's configuration, which may name a program, and the approver judges only the working tree's own.
