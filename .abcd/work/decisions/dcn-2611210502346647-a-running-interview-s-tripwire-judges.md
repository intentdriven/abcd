2026-11-21 — A running interview's tripwire judges the pre-push gate exactly as the hook will judge it (iss-2611012144422634, iss-2610040739124513), refining dcn-2611210421357881. Its git reads see history as stored, with replacement refs, graft files and the commit-graph off as the hook sets them, so a replace ref can no longer hide that a planted remote-tracking ref holds HEAD. It takes the worktrees from the same newline listing the hook reads, line by line, and a worktree whose path holds a newline stops the interview with a plain message, since the hook would read that path as more than one worktree. It counts a receipt only by the hook's own checks: the pushing checkout first, then each listed worktree; a regular file; a worktree git can list files in; nothing tracked that is .abcd or lies in its local tier in any letter case; and no tracked path whose first two segments open the same directories. Of the two review notes, the first stays as it is and the second is fixed. It judges HEAD alone, not every local branch tip: judging every tip would let a peer's own preflight or fetch in its worktree stop the interview again, the false stop dcn-2611210421357881 removed, and a push of another branch is that branch's own preflight to answer. info/refs in the common directory and each submodule's git directory is no longer read: only git update-server-info writes it, for clients of a dumb transport, no local git command and not the pre-push hook read it, and it runs nothing, so a peer's gc rewriting it no longer stops the interview, while the rest of info/ is still read. The pages now also name an entry with no commondir, and a worktree added where per-worktree configuration is on, which git gives a copy of the source worktree's config.worktree, among what stops the interview.
