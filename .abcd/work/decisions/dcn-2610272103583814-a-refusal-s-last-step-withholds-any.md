2026-10-27 — A refusal's last step withholds any argument the caller typed that still stands whole in it, and keeps three kinds: an argument under eight bytes, a command name, and a record id matching recordid.CitedIDRe, the one shared id grammar. Grounds: one step at the error boundary covers every verb, including a site no per-site rewording reached; shorter arguments are counts, letters and short words whose every occurrence would otherwise be rewritten; a command name and a well-formed id are what a refusal must name to be usable; and matching whole words only keeps a short argument from rewriting the inside of a longer word. A verb that writes its own --json document ahead of the error object is outside the step, so its own wording must not repeat the argument (build's key check is changed for that reason). Decided by abcd-0b (technical, delegated).
