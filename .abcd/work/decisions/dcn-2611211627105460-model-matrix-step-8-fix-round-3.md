2026-11-21 — Model-matrix step 8 fix round 3 (itd-2610161733316518, spc-2610161949559050): the limits the identity scrub of a copy's text still leaves, named and accepted. The scrub withholds a model's or maker's name written straight on, in any case and inside a longer word; through compatibility forms, combining, enclosing and spacing marks, format characters, Hangul fillers and controls other than white space; with every dash read as a hyphen; in the Cyrillic, Greek and Armenian look-alike letters its table holds; and, where it is the whole name, with its letters split by single separators. It does not stop the following, and matching strings cannot. (1) Look-alike letters of scripts outside the table (Cherokee, Coptic, Lisu and others): the set of confusable letters is open-ended and grows with Unicode, and folding every script that has a Latin look-alike would rewrite ordinary text written in those scripts. (2) An encoding, such as base64, rot13, hex, an acrostic or a spelled-out alphabet: the name is not in the text as its letters at all, and decoding every possible encoding to look for it is unbounded and would find names by chance in ordinary text. (3) Stylometry: a copy's length, formatting, wording and habits sign the text as a whole, not any span a scrub could withhold. (4) Separator forms the separated match does not cover: a gap of two or more separators (c--l--a--u--d--e, a hyphen with a line break), digits between the letters, a name split by spaces at some gaps but not all (Clau de), a line break inside a name shorter than five letters, and a separated name shorter than four letters other than the families' and developers' own (gpt, glm, phi, xai). Each would make ordinary prose read as a name if matched: met a reads as meta, op us as opus, and a line wrapped between met and a as meta again. The blind is a barrier against a copy naming itself plainly or in a respelling, not against a copy set on signalling its model.
