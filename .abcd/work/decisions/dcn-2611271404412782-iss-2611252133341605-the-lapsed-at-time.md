2026-11-27 — iss-2611252133341605: the lapsed_at time fields of the release-withdrawals listing (ReleaseWithdrawals) and the armed-merges check (ArmedMerges) in internal/core/claim take omitzero rather than becoming pointers. Grounds: omitempty never drops a zero time.Time, so an unlapsed release printed 0001-01-01T00:00:00Z; omitzero (Go 1.24, used elsewhere in the tree) drops it with a one-word change and leaves every Go reader of the field, which reads it only beside Lapsed, untouched, whereas a pointer would change each assignment and reader. ArmedMerges carries the same omitempty-on-a-time defect, so it is fixed in the same change. Reverse by turning either tag back to omitempty or by making the field a *time.Time as SettleRelease.LapsedAt is.
