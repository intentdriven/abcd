2026-10-16 — Refines dcn-2610161826443524 on when a pending hand-back ends (facilitator-on-delegation, drain-many-accounts review round 2): it ends only when a release publishes it, or when it is no longer due: a tip already marking a hand-back, a record finished or changed on origin's default branch since the yes was judged, a record origin holds in no one file, or a tombstone the hand-back would take past its cap. A move that ends it unpublished says in its next step and in the route that it was dropped, and why, and never that it was published. A release that could not read origin's default branch at all (this checkout names none, or its tree would not read) keeps it pending, whether the release pushed a plain tombstone or found one already there, since that failure says nothing about the record and passes; the next move's release publishes it once the branch reads (grounds: dcn-2610161826443524, dcn-2610161837009957; spc-2610161044461448 steps 2 and 3; the re-review of the fix round).
