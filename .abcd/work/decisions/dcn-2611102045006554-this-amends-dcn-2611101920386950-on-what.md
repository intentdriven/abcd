2026-11-10 — This amends dcn-2611101920386950 on what the code now does. The stop check counts a waiter's command as the preflight's stages only in the Makefile's exact shape: its program is make or gmake by base name, and every word after it is --no-print-directory or the single goal preflight-stages, named once; any other flag, a flag's value, a variable assignment or a second goal makes it count for nothing, and the environment is not read. Only the preflight writes a whole run's marker, and only the preflight says a note, at the look that fails to write it; another command run through the gate writes none. The sweep removes a file named as a marker that a reader refuses, except two: a file of a higher schema version, which the later build that wrote it sweeps, and a file whose name gives a pid the reading holds. A marker whose start is after the reading began is left as written after it, unless its start is later than the reading plus five minutes, when it is judged as an old one. Five minutes covers what comes between a reading and the sweep, the process read under its own timeout (twenty seconds where ps is run) and the HEAD read under its ten-second bound, with room to spare. Left unswept, then, are a higher-schema file whatever its pid and a refused file named for a live pid while that pid lives; enough of them can fill the 256 entries a look takes in. Both fail safe: the reader counts neither, and a marker past the look counts its run as not live, so the stop check falls back to the two-wake rule.
