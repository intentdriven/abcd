2026-11-13 — A drive holds what its own git reads, in the environment that git runs in. It asks git which hooks directory it runs, through the same command and environment as the lane's add and commit, and expands no path itself; where git cannot answer, the lane or the start stops. It lists the watched settings in both environments its git runs in, the ask of origin and the lane's add and commit, holds each listing against its own earlier one, and holds by their bytes the files that include settings name, whatever their condition, and the global and system attributes files git names. A committed hook that is a link is proved through the link against the commit's content where its target stays in the working tree; where the target leaves the tree, the drive refuses its start once, saying the links are the repository's own and a drive runs no lane there. The start-time comparison of an in-tree hooks copy is with the tip origin reports at that moment, under settings taken as they stand; it narrows what a restart takes on trust and does not remove it, and its refusal says whether files differ, the checkout is behind the tip, or untracked files stand in the hooks directory. A start that cannot reach origin for a network reason waits as a lane's ask of origin waits.
