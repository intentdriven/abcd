2026-11-10 — iss-2611100548341325 is split. Lane q builds an audit of the git calls the hooks reach that take no context, with a checked-in baseline of today's reached calls. The audit fails on any reached call not in the baseline and on any baseline entry that is no longer reached, so the list can only shrink. Later lanes bind the named reads, then the rest, removing baseline entries as they go. The docs say 'every' only once the baseline is empty. Grounds: about 800 context-free call sites, of which the reached subset is unknown; a ratchet is the usual way to migrate a large codebase step by step without a flag day. Reverse: delete the baseline and make the audit strict.
