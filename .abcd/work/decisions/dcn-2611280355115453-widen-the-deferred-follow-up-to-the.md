2026-11-28 — Widen the deferred follow-up to the inlined-SVG naming change (dcn-2611272337491591, iss-2611272337581253) to every spelling the asset check reads differently from the page: any attribute name carrying a non-ASCII byte, not only one behind the aria- prefix, any prefixed element name, not only one example, and a prefixed pointing attribute (href or src under any prefix other than xlink), which the check settles on its local name. Grounds: the reviews of the naming change and of this widening found the narrower wording left these cases out, and the follow-up should name each case it knows of so its fix sweeps every sibling; the fix's own review checks for any further one. The deferral itself stands for the same reason as before. Reverse by narrowing the issue's remedy back to the named cases.
