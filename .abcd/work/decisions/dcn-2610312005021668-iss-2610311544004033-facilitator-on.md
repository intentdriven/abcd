2026-10-31 — iss-2610311544004033, facilitator on delegation: the inline form is chosen by where the owner puts a part, not by a new setting or flag. A part whose opening mark is a continuation line of an open block-level HTML block (CommonMark types 6 and 7, such as a `<p>` or `<div>` block, which run to the next blank line) is written as HTML, because Markdown inside an HTML block is never rendered; a part anywhere else is written as today. Grounds: CommonMark 0.31 HTML block rules; a body that cannot render where it stands is a defect, not a preference.
