2026-11-10 — A drive consumes an implementer's receipt only when it is refused for the work it reports: it names this run, this lane and this branch in the schema abcd reads, and the verifier still finds gaps. Every other refusal (a file that is not a receipt, another run's or lane's, a hand-back, a fix round with no new commit) keeps the stop and is ended by the drain's stuck bounds, so a file nobody launched for never starts a paid relaunch. The drive gives a stuck lane back to the next drain move, which hands it back as before; the same lane given back twice in a row waits first, as an idle drive does (iss-2611071242184002).
