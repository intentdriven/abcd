2026-11-26 — A person's own facilitator setting (itd-2611252049031692) is read only where HOME is the account's own home, the one the account database names for the account. A hosted environment whose home is its own is read as a computer of its own: what that home holds is that computer's setting, and the project's committed value stands above it. The merge gate reads a person's own auto as human until the check of who opened the pull request lands (the intent's decision 7). Grounds: a session can run under a HOME the person did not set up, and the opener check is not built yet. To reverse: remove the account-home comparison from the person reading and its tests, or lift the gate's hold once the opener check is in, each in a change that records the reversal.
