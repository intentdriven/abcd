2026-10-23 — Release hold (iss-2610222014550692), round 5, ruled by the coordinating facilitator on delegation while the product thinker is away. A person admitting a pull request that another person withdrew, after taking over their release, is refused, with the reason and the remedy named: the withdrawer admits it, or takes the release over themselves. This matches the rule that another person's copy never re-arms, and a refusal can be relaxed later, where an arm made across accounts cannot be undone. Every real disarm abcd makes gets a comment, including a first withdrawal made on a retry and a second one after the owner re-armed by hand. The comment sentences are fixed: re-armed reads 'abcd release hold: the merge of #N is re-armed; the hold for release vX has ended.'; already armed reads 'abcd release hold: the merge of #N is armed; the hold for release vX has ended.'; not re-armed reads 'abcd release hold: the merge of #N is not re-armed; the hold for release vX has ended.' followed by one clause: head moved 'Its head changed while it was held, so its owner needs to re-arm it.', no merge queue 'It can merge now and there is no merge queue, so its owner can merge it.', refused 'GitHub refused to re-arm it five times, so its owner needs to re-arm it.', closed 'It was closed.', merged 'It was merged.'. The pull request lists every sentence so the product thinker can review the posted wording before the first real cut posts it. A change to a withdrawal's state counts only when the withdrawer's own push carried it, and a tombstone ends the hold only when the holder pushed it; anything else is reported and not acted on.
