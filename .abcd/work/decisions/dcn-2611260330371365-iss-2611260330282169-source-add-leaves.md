2026-11-26 — iss-2611260330282169 (source.Add leaves an orphan key folder after a kill part-way through an add) is deferred out of the change that makes fsutil.CreateExclusiveIn write a write-once file whole (iss-2611260251214135). source.copyFile's own exclusive file write is sound; the defect is that Add writes several files into the key's folder with no transaction, so an interrupted add leaves the folder behind and every re-add of that key is refused. Fixing it means staging the whole add and moving it into place as one step, a transactional change to source.Add that the write-once primitive does not provide and that is out of this change's scope.
