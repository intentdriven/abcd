2026-11-08 — Model-matrix step 3 (itd-2610161733316518, spc-2610161949559050), the technical facilitator on delegation, from the lane's first review round: a trial run lives in its copy's own clone of the frozen commit, in the matrix's clone store, and never in the person's checkout. A trial's start names its frozen commit, which must be the full id of the checkout's head; the run's state records it, and every lane is cut from it, so no lane starts from the default branch's moving tip, the clone needs no default branch, and no copy's lanes share another copy's refs. The step that starts trials must give the clone an empty local tier for the run's own state after the clone's checks pass; that tier holds no file of the person's, and nothing makes it yet. A trial builds one spec step: it lands nothing, so a later step's lane would be cut from a commit without the earlier one, and a spec leaving more than one step is refused until a trial cuts a dependent lane from the head of the lane it needs. Inside a trial the loop dispatches in the runners' cell mode: a runner that fails, refuses or answers unparsably hands the lane back as the cell's failure with no fallback receipt, and no later step retries it; a provider down before the copy began pauses the role for its own runner, again with no fallback receipt; and no role of a trial is released to the host.
