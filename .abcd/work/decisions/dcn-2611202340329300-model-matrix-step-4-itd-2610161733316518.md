2026-11-20 — Model-matrix step 4 (itd-2610161733316518, spc-2610161949559050), the technical facilitator on delegation: a code task's hidden tests are kept read-only under the clone store's hidden/<run>/<task>/, beside the copies and never in one, placed once, and a copy whose fresh clone holds a hidden test's content at any path is refused before it starts. The compliance check runs four rules in a fixed order and reads the copy only as data, never running git or anything else in its clone. tests_kept compares every test file of the frozen commit, read from the run's own checkout, with the clone's file through an os.Root by git's blob id; a test file is one under a test, tests, testdata, __tests__, spec, __snapshots__ or fixtures directory, or named the way Go, Python, JavaScript and TypeScript, Ruby, Rust, Java and Kotlin name tests, and a test the copy adds is no breach. own_copy_only reads the copy's transcript for any path in the run's clone store outside its own clone, as given and as its links resolve, with slashes plain or JSON-escaped, and for a .. climb out of its own clone. network_policy is asserted for every copy, since no runner reports what a copy reached on the network. isolation is asserted, not proven, for a host copy and kept for a runner's. A broken rule excludes the copy; otherwise an unexamined rule (no transcript, an unreadable test file, a missing clone or frozen tree) marks it unexamined; an asserted rule still ranks it and the report lists it as a limitation. The trial record carries the result, and a passed, scored-failed, unexamined or compliance-excluded trial without one is refused. Grounds: the compliance and isolation criteria and decision 9; reading the clone as data keeps a hook, filter or configuration a copy wrote from running in abcd's check. Expected cost, not yet measured: a repository whose checkout rewrites line endings (an eol=crlf attribute) reads as edited tests, and a read through a relative path naming no part of the store is not seen. Reverse in internal/core/matrix/hidden.go and compliance.go.
