2026-11-08 — Model-matrix step 3 (itd-2610161733316518, spc-2610161949559050), the technical facilitator on delegation: each copy's clone is a fresh repository made with an empty template and a fetch of the frozen commit alone, one commit deep so it holds none of that commit's ancestors and what a copy can read in it is the frozen tree the scan reads, checked out on a detached HEAD, under the account's abcd home at matrix/<root-sha>/<run>/<task>/<cell>/<repeat>, beside the worktree store; a store inside any repository (the source, its worktrees, any other) is refused, a key whose clone exists is refused, and a frozen commit tracking the local tier is refused. Every clone passes the launch bundle's scan, read with the run's own checkout's scanner configuration, except a local or host cell's, which is sent nowhere new; a pin of an empty or unknown source is scanned as a provider's is, and a hit refuses the cell. The step that wires a cell's pin to its runner must enforce that a local pin routes only to a runner that keeps the work on this machine, and refuse a local cell whose route reaches a provider over the network, since its clone is never scanned. The one local server slot refuses a second cell's server while the first runs rather than stopping it, so a server is stopped only when its own cells end. Grounds: decision 4 and the isolation, scan and one-server criteria; a fetch of one commit holds no branch, remote or other copy's refs by construction, which a full clone would. Expected cost, not yet measured: a repository whose tests carry secret-shaped fixtures, as abcd's own launch tests do, would have every provider cell refused until its scanner configuration excludes them. Reverse in internal/core/matrix/clone.go, cell.go (admitClone) and localserver.go.
