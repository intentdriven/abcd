2026-11-05 — The off-profile warning is one line on the verb's stderr, printed after the move. While the away mode holds it reaches the agent alone, and nothing records it for the person's return, because no one existing call fits: a queued step is an act for the person to approve, and a recorded stop reads on return as a stop. dcn-2611041550129278 asks for a line that cannot be missed, so carrying it to the person's return stays owed under the itd-2611040344170206 criterion opening "Given a session that is not on a profile".
