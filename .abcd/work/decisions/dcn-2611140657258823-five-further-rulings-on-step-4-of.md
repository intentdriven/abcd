2026-11-14 — Five further rulings on step 4 of spc-2610301925429250, made by the technical facilitator on delegation; they add to dcn-2611140407301478 and amend nothing in it. First, two model names count as other models only when that is shown: each name is reduced to a set of tokens (lower-cased; a bracketed suffix and everything up to the last slash dropped; split on every character that is not an ASCII letter or digit; a trailing v-number tag with what follows it, a trailing eight-digit date and a short fixed list of vendor, carrier, region and alias words dropped), a name holding a non-ASCII or control character or leaving no token is unknown, and two names are other models only when both are known and neither token set is contained in the other. This replaces the prefix comparison the earlier record describes; the matrix's strict comparison and its answers are unchanged. Second, the writers of a lane are every model that wrote into it up to the round: for each implementer, fix-round and conflict-resolution receipt, the model its runner reported and the model the receipt named where that is a known name; a reviewer must be another model than each of them, and a round with neither a runner's report nor a known receipt name leaves its writer unknown, so the lane hands back as stuck. Third, at a reviewer's return every name the loop holds for it (the class model asked for, the model its runner reported and the model its return names) must be another model than every writer, and the record keeps the runner's report, else the model asked for, with the named model beside it where that is another. Fourth, what is read back from the run state is held to the rest of the same file: the stored writers to what the lane's receipts give, each class map entry to the set's reviewer of that class, a moved reviewer to the move recomputed from those, and a reviewer that was handed out but names no model only where it was marked as a file of an earlier version was read, in a run started before version 27. Fifth, a moved reviewer lands only on a class the drive's runners could launch when the run started, and passes over a class another reviewer of its role holds while a further class qualifies; main has no rule that a role's reviewers are different models, so the move prefers one. Grounds: a doubtful comparison counts as the same model, since a change reviewed by its writer's model while the record names another is the costly failure, and a record names what ran. To reverse: replace the token comparison in internal/core/matrix/samemodel.go or the writers' list in internal/core/implement/loop/reviewers.go, in a change that says why.
