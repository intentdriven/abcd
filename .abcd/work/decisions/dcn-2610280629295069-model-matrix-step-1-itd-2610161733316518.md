2026-10-28 — Model-matrix step 2 (itd-2610161733316518, spc-2610161949559050), the step that first writes a procedure's records, makes the lab sweep pass over them, and step 1 leaves the sweep as it is. Grounds: the sweep exempts a probe's capture files as instrument output (its input, command line, exit status and output); a matrix declaration is a run's input and its run and trial records are what it ran and measured, never rewritten, so a retraction swept into one could never be applied and would halt the lab for good. The exemption keeps the sweep fail-closed: it covers only the regular files, within the record bound, whose paths a procedure can write under state/matrix/, so anything else there is still read or listed as not swept; and the same change adds state/matrix/ to the sweep's documented exemptions in the lab sweep help, the generated CLI reference and the lab brief. Step 1 cannot carry it: nothing writes there before step 2, and the generated reference is held by other reservations tonight. Found by the step 1 review pair.
