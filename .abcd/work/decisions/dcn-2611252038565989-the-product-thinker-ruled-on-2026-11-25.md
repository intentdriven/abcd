2026-11-25 — The product thinker ruled on 2026-11-25 whether abcd may install a newer release of itself without asking each time: not by default, and yes where the technical facilitator is set to auto. It answers the question adr-2611251808065076 left open in its second point. Read with the third point of that record, which stands, the writing session takes it that the setting must be the person's own on their machine: facilitator.mode is also read from a repository's committed file, and no repository file may make a computer install anything. A repository that says auto therefore turns nothing on by itself. Nothing is built on this ruling yet; the ADR is refined when it is planned. To reverse: install only on the person's act.
