2026-10-31 — iss-2610311544004033, facilitator on delegation: placement. An absent part whose nearest present part is inline goes on the line beside it, with no blank line between, in the inline form, so it joins the same HTML block. With no part present, an absent part goes after a leading frontmatter block, else after the first live level-one heading, a Markdown # line or an HTML `<h1>` line outside every code fence, else at the top; there it is written in block form, set off by blank lines. Removing an inline part leaves no blank line in the block it sat in.
