check-attribution.sh's GENERATED_RE misses the italic footer form a hosted agent platform actually appends: `_Generated by [Claude Code](...)_` starts with an underscore, and the regex anchors '^[[:space:]]*(robot)?[Gg]enerated (with|by) [' — so the exact footer shape that motivated the gate sails through the body check when wrapped in markdown italics. Admit an optional leading '_' or '*' (and matching trailing) in the shape. Found live: both walkability PRs carried the italic footer and the body check did not flag it; the failing leg was commit identity.
