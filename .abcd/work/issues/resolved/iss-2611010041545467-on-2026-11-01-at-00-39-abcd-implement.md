On 2026-11-01 at 00:39 abcd implement receipt refused a build run's receipt because the run's state.json was schema version 17 and the binary that answered reads versions 1 to 16. The run had been started through the main checkout's scripts/abcd.sh, which builds and runs whatever that checkout has checked out; a peer session working in the same main checkout switched its branch to an older one in between, so the next invocation rebuilt an older binary under the running session. A session's abcd should not change because a peer switched the shared checkout, and the refusal's remedy (abcd update) does not apply to a source checkout.
