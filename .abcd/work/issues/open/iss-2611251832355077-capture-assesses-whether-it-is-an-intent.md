Capturing an issue does not assess whether what is filed should be an intent. The capture page says where a user-facing change goes and leaves the choice to whoever files; the verb checks text, remedy, and likely doubles, and asks nothing about kind. Met on 2026-11-25: a request for new behaviour, that abcd holds a session to capturing what it confirms, was filed as an issue, and the product thinker had to ask whether it was an intent before it was promoted. Two more filed the same evening read as capabilities too: that every copy of abcd is kept current (iss-2611251742484774), and that an ideate run says what it needs before it starts (iss-2611251828573245). Beside it, the decomposition table routes a proposal only when an intent is being filed.
