The rules a leg 3 reviewer of /abcd:ideate must be given exist only as prose in the command page, and the binary that judges the verdict cannot print them. `abcd explain ideate record --input verdict-json` lists `current_state` as a required string and shows one value, `ignore`, in its example, with neither the other value nor what each obliges the host to tell the reviewers. The first time the binary judges anything a run produced is `ideate record`, after all three legs. A dry run made before leg 3 is always refused (exit 2), and it names one fault at a run in a fixed order, after the idea itself: the overall verdict, which a run does not have before leg 3, then `current_state`, then the leg count (the gauntlet is exactly 3) and the order of the legs, and only then `origin_sources`, leg 1 and leg 2. So before leg 3 the host can have those checked only by writing in a verdict it has not reached and a third leg that holds its kind and nothing else, and by reading a refusal that names the missing reviewers as a pass; no page says to try that. Even then only their shape is judged: whether a cited record id resolves and whether a source key is filed are checked after the reviewers are, so no document can have those checked before leg 3. The leg 3 brief itself (authorship stripped, findings without their narrative, the rule for the mode, the reply shape) is composed by hand each run, and no reviewer agent ships for it as one does for the lifeboat review. A rule that changes the review is therefore found only once the reviewers have returned. On 2026-11-20 two sessions in the abcd source checkout each ran the gauntlet from the v0.16.0 page, which predates the current-state mode (iss-2610310815034547). The recorder refused both verdicts for the missing field after leg 3. One session discarded its reviewer pair and ran a fresh pair under the rule; the other resumed both reviewers, and one first-pass fatal from each was downgraded. A resumed reviewer judges again with its first answer in view, which weakens the fresh context leg 3 exists for, and the verdict document has no field to say a review was briefed twice. Why those sessions held an old page is iss-2610241228359748; this record is the part that stays true with a current page, since the installed page a session in a source checkout is served is older than the tree by construction. The remedy does not reach a page from before v0.17.0, which carries no ask-the-binary block and so sends the host to neither explain nor the new step; such a session composes the brief by hand as today. The wording of the ask about the sources of a reviewer is iss-2611211025172155, which changes the same leg 3 section.
