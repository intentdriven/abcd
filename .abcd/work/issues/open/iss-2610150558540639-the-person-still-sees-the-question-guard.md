The person still sees the question guard's refusals as errors while a session rewrites a question. On 2026-10-15 one question to the product thinker was refused three times before it reached them: the header, three sentences per option, the row limit, a missing Change later line and a named command. Each refusal showed on their screen as a hook error, because the session drafted the question itself instead of through the drafting agent

The error framing of a guard refusal on the host is its own open finding, iss-2610070637562567; this record is about the session skipping the drafting step that would have avoided the refusals.
