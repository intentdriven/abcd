The product thinker has no convenient way to file an issue, a new intent, an idea for the ideate gauntlet or a lab request away from a terminal, for example from a phone. The planned dashboard (itd-2610032150577708) lets them read the record on a phone and leave a note on a brief line, but not start any of these records, so a thought on the move waits until they are back at an agent session.
