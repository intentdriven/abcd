While the away mode holds, the stop check handed a branch one session had just made to every other session as work it owes. On 2026-11-21, within minutes of the away mode being set, two sessions each had a turn end answered with one owed item: a branch a third session had made minutes earlier and committed to in its own worktree of the store, not yet pushed, with the instruction to do the local work and then push. Both recognised it as a peer's and left it. A session that obeyed would have pushed a peer's commits before their checks had run. All three sessions had been started in the main checkout. The branch had been made with git branch at a commit, in a shell line that first changed into a store worktree, and then checked out through the worktree store's add verb with its existing-branch option. The created-branch record of the start copy held the name with no session key, as it holds every one of its 31 entries, the newest among them. At this head the recorder already writes the key the guard hook's payload carries, a change first tagged in v0.17.0, and 20 of the 31 entries are dated after that change landed. This machine has no dogfood opt-in, so its hooks are served by the installed release, which this session's plugin root has at v0.16.0: the entries were most likely written by a release older than the key. The reader's rules are deliberate and stay: a branch another worktree has checked out is dropped unless this copy's sessions recorded creating it or made a worktree for it, a branch the stopping session created is owed to it, and a branch with no session key stays owed (iss-2611020719483054, iss-2610311406481214). So the keyless entry was owed to every session whose stop check reads that copy. The same evening the stop check told the session that had made the other branch of the same work, through the store's add verb with a new branch, that nothing was owed while that branch held five commits not pushed: that branch's name is not in the record at all. The recorder reads only git command lines and is the record's only writer, so a branch the store's add verb makes is never recorded.
