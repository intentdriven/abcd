# consult-only-advisor-role

## Summary

The tier escalation of spc-2609251028149555 is built: a failed round's next
round asks one tier up for each tier-routed reviewer, recorded in the run
state (Decision 6). This spec holds itd-2609170822093401 open for the role the
product thinker asked on 2026-10-14 to add to it: a consult-only advisor, which
gives advice after a configurable number of failed rounds and never executes
anything itself, with its default threshold grounded in a state-of-the-art
check. The intent does not describe that role yet, so its criteria are added
to the intent before this spec is planned; until then the intent stays
planned.
