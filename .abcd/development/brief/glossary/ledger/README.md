# Ledger context

The `ledger` bounded context holds the vocabulary of the warm inference
ledger and the cold-reading instrument: the terms the construal in the
framing chapter is written in, which a widening reading is handed as
committed vocabulary under the admissibility rule of adr-55. Each term is the
term as it presently stands; the dispute that settled it, where there was one,
stays on the local ledger side and is not recorded here.

Each term is a Markdown file with YAML frontmatter in the shape the glossary
README specifies. For that shape, the checks that read it, and the full term
index, see the [glossary README](../README.md).
