# Interview context

The `interview` bounded context holds terms specific to the grill/interview
sub-verb of `/abcd:intent` — the interactive exchange (session), its opening
move (embark), and the knowledge floor its questions are held to. These pin vocabulary that means something narrower here than in the
core context.

Each term is a Markdown file with YAML frontmatter in the shape the glossary
README specifies. For that shape, the checks that read it, and the full term
index, see the [glossary README](../README.md).
