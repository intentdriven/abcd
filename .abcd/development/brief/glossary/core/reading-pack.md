# reading-pack

A **reading pack** is what the librarian hands back. It lives on the person's machine, owner-only, and is never committed. Ideate tests ideas from it; the research command turns an approved pack into a shared research note.

## When to use

For the private output of a librarian run.

## When NOT to use

For a shared, citable note: that is a research note. For a page in the memory store: that is a memory page.

## Examples

- A pack from an old game's manual lists its design principles, each quoted from its page, and says the manual is all rights reserved.
