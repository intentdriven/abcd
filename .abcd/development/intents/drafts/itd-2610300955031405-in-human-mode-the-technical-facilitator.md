# A merge approval can require a security key touch

## Press Release

> In human mode, the technical facilitator's approval of a merge can require a touch of a hardware security key, so that an approval shows a person was present when it was given. Today an approval is a rule agents keep: anything running as the person's account can record one. With this, the key signs the approved head commit when touched, and the merge gate counts a recorded approval only when it carries a signature that key made. It is later work, after agents can work under a forge account of their own.
