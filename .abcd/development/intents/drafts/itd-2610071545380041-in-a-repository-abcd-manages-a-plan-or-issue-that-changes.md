# Work about abcd itself goes to abcd as a report, never into a managed repository's own plans

## Press Release

> In a repository abcd manages, a plan or issue that changes abcd itself (its commands, checks, hooks or pages) belongs to abcd, filed as a report, while what the repository decides about its own use of abcd stays in the repository and cites the report. abcd keeps such work out of the repository's own record three ways: it teaches the convention in a bundled rule recalled on intent, capture and decomposition work; decomposition routes a part that changes abcd's own surfaces to a report by default, and a decision to keep it in the repository is recorded with its reason; and intent and capture warn, without refusing, when the text names abcd's own surfaces, naming the report route. Product thinker's ruling 2026-10-07 (interview on iss-2610071538088019, promoted from a managed repository's report): teach, redirect and warn, all three.
